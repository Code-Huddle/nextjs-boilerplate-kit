# Code of Conduct

## Our standard

We want this project to be a safe, constructive place to collaborate. Be
respectful, assume good intent while still discussing evidence directly, and
focus criticism on ideas and code rather than people.

Examples of welcome behavior include:

- giving specific, actionable feedback;
- acknowledging mistakes and correcting them;
- respecting different backgrounds, identities, experience levels, and points
  of view;
- protecting private information and security reports;
- helping keep discussions relevant and technically useful.

Harassment, threats, discriminatory language, sexualized attention, deliberate
intimidation, doxxing, sustained disruption, or retaliation are not tolerated.

## Scope

This standard applies in repository issues, pull requests, discussions, code
review, project events, and public interactions where someone represents the
project.

## Reporting and enforcement

Report conduct concerns privately to `haris.ahmed@code-huddle.com`. Do not open
a public issue containing sensitive personal information. Maintainers will
review reports as confidentially and promptly as practical, may request more
context, and may remove content, issue a warning, temporarily restrict
participation, or permanently ban participation depending on severity and
history.

Maintainers must recuse themselves when they are directly involved in a report.
Good-faith reporters and participants will not be retaliated against.
