# Governance

`nextjs-boilerplate-kit` is maintained by Code Huddle contributors.

## Maintainers

- Kashif Abbas Kazmi
- Haris Ahmed

Maintainers triage issues, review pull requests, manage releases, respond to
security reports, and uphold project conduct. Maintainer status is based on
sustained, trusted contributions and consensus of the existing maintainers.

## Decisions

Routine changes are decided through pull-request review. Security fixes may be
developed privately until coordinated disclosure. Material changes to the
generator contract, supported platform, licensing, or security model should be
documented in the pull request and changelog and should receive approval from
at least one maintainer who did not author the change.

When consensus cannot be reached, maintainers prefer the option that preserves
security, backwards compatibility, deterministic generation, maintainability,
and clear user choice, in that order. The repository organization retains final
responsibility for releases and project direction.

## Releases

Maintainers publish releases from reviewed commits that pass required quality
gates. Release access should use least privilege, protected branches, two-factor
authentication, and npm trusted publishing with provenance when available.

## Changes to governance

Governance changes use the same public pull-request process and should explain
why the new model improves accountability or contributor participation.
