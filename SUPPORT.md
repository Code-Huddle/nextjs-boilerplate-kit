# Support

## Where to ask

- Use [GitHub Discussions](https://github.com/Code-Huddle/nextjs-boilerplate-kit/discussions)
  for setup questions, ideas, and community help.
- Use [GitHub Issues](https://github.com/Code-Huddle/nextjs-boilerplate-kit/issues)
  for reproducible bugs and accepted feature requests.
- Use private reporting from [SECURITY.md](SECURITY.md) for vulnerabilities.

This is a community-maintained open-source project. Support is best effort and
has no guaranteed response or resolution time.

## A useful support request includes

- operating system and architecture;
- `node --version` and `npm --version`;
- generator package version;
- the complete generator command with secrets removed;
- selected auth, ORM, payment, and optional modules;
- the exact failing command and complete relevant error;
- whether the failure reproduces in a freshly generated project.

Please reduce large application-specific reports to an unmodified generated
sample whenever possible.
